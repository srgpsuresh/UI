Hands-on Lab (Windows 10)

Step 1 - Install Visual Studio Code

Purpose: IDE used to write Angular code.

  1. Download Visual Studio Code.
  2. Run the installer.
  3. Accept License Agreement.
  4. Click Next.
  5. Select "Add to PATH".
  6. Click Install.
  7. Launch VS Code.

Step 2 - Install Node.js (LTS)

Purpose: Required to execute Angular CLI and npm.

  1. Download Node.js LTS (20.x).
  2. Run Installer.
  3. Accept License.
  4. Click Next.
  5. Install npm.
  6. Click Finish.

Step 3 - Verify Node.js

Open Command Prompt.

node -v

npm -v

Expected Output

v20.x.x

10.x.x

Step 4 - Install Angular CLI 17

npm install -g @angular/cli@17

Wait until installation completes.

Step 5 - Verify Angular CLI

ng version

Expected Output

Angular CLI : 17.x.x

Step 6 - Create Workspace

cd D:\

mkdir AngularProjects

cd AngularProjects

Step 7 - Create Angular Project

ng new EmployeeManagement

Select Options

Question Answer
Routing Yes
Stylesheet CSS
SSR / SSG No

Step 8 - Open Project in VS Code

cd EmployeeManagement

code .

Step 9 - Run Angular Application

ng serve

Angular starts the Development Server.

Step 10 - Open Browser

http://localhost:4200

The Angular welcome page appears.
