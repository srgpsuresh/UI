Step 1 - Generate Header Component

Command

ng generate component components/header

Purpose

Creates a reusable Header Component.

Generated Files


src/app/components/header/

│

├── header.component.ts

├── header.component.html

├── header.component.css

└── header.component.spec.ts

Step 2 - Generate Sidebar Component

ng generate component components/sidebar

Creates Navigation Menu.

Step 3 - Generate Dashboard Component

ng generate component components/dashboard

Displays Employee Dashboard.

Step 4 - Generate Footer Component

ng generate component components/footer

Displays Copyright Information.

Interview Questions

What is a Component?

A reusable UI building block consisting of HTML, TypeScript, and CSS.

Why Components?

To divide a large application into smaller, reusable, maintainable parts.

What is a Parent Component?

A component that contains other components. Example: AppComponent.

What is a Child Component?

A component rendered inside another component using its selector.

How are Components displayed?

Angular replaces the component selector (e.g., <app-header>) with the HTML from HeaderComponent.
