What is a Component?

A Component is a reusable UI block. It contains

  • HTML (View)
  • TypeScript (Logic)
  • CSS (Design)

Real-Time Example

Each section is an independent Component.

Why Components?

Without Components With Components
One HTML file 10000 lines Header Sidebar Dashboard Footer
Difficult Maintenance Easy Maintenance
No Reuse Reusable
Hard to Debug Easy Debugging

Step 3 - Component Selector

Header Component Selector 


selector:'app-header'

Use inside app.component.html 


<app-header></app-header>

Step 4 - Import Component (Angular 17 Standalone)


imports:

[

HeaderComponent

]

Without importing the component, Angular cannot recognize <app-header>.

Step 5 - Rendering Flow

ng serve ↓ angular.json ↓ index.html ↓ main.ts ↓ app.component.ts ↓ app.component.html ↓ <app-header> ↓ header.component.html ↓ Browser

Common Errors

Error Reason Solution
'app-header' is not a known element HeaderComponent not imported Add HeaderComponent to imports[]
Nothing displayed Selector missing Add <app-header>
Compilation Error Wrong Import Path Correct import statement
