Step-by-Step Execution

1. ng serve

Purpose

  • Starts Angular Development Server.
  • Compiles TypeScript into JavaScript.
  • Runs the application on http://localhost:4200.
  • Automatically refreshes the browser whenever files are saved.

Command

ng serve

2. angular.json

Purpose

  • Main project configuration file.
  • Identifies which Angular project to run (EmployeeManagement).
  • Specifies the src folder.
  • Loads global styles.
  • Loads assets.
  • Controls build and serve options.

3. src/index.html

Purpose

  • First HTML page loaded by the browser.
  • Contains the root Angular tag.
<body>
    <app-root></app-root>
</body>

Angular replaces <app-root> with the application's UI.

4. src/main.ts

Purpose

  • Main entry point of Angular.
  • Starts the application.
  • Bootstraps the root component.

Flow

ng serve
      ↓
main.ts starts
      ↓
Bootstrap Angular

5. app.config.ts

Purpose

Application Configuration File.

  • Routing Configuration
  • Register Services
  • HTTP Client
  • Dependency Injection Providers
  • Animations

Example

provideRouter(routes)

provideHttpClient()

providers:[]

6. app.routes.ts

Purpose

Navigation (Routing) File.

Maps URLs to Components.

URL Component
/ Home
/employee Employee
/department Department
/login Login

7. app.component.ts

Purpose

  • Main Component.
  • Contains Business Logic.
  • Handles Events.
  • Calls Services.
  • Processes Data.

Example

Employee Management
↓

Load Employees

↓

Display Employees

↓

Save Employee

↓

Delete Employee

8. app.component.html

Purpose

  • User Interface (UI).
  • Displays data.
  • Buttons, Tables, Forms.
  • Uses Angular Bindings.

Example

  • Employee List
  • Add Employee Form
  • Edit Button
  • Delete Button

9. app.component.css

Purpose

  • Styles the component.
  • Colors.
  • Fonts.
  • Spacing.
  • Responsive Layout.

10. Browser Output

Finally the browser displays the application.

http://localhost:4200
